# Assil Barhoumi — portfolio

**Live site: [assil-barhoumi.github.io/assil-barhoumi](https://assil-barhoumi.github.io/assil-barhoumi/)**

My personal portfolio: projects, internships, skills and contact details.
Built with React, TypeScript and Vite, styled with CSS Modules.

## Structure

- `src/data/` — all the content: profile, projects, experience, skills, education
- `src/sections/` — the home-page sections
- `src/pages/` — case study and internship pages
- `src/components/` — header, footer, icons, figures and shared UI
- `src/lib/` — routing, theme and hooks
- `public/` — images, CV and icons

## Run locally

```bash
npm install
npm run dev
```
